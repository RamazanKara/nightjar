## en
- Starting a game while another one runs on a Rubylight PC closes the running game only when you confirm the prompt. A remembered launch or a cancelled prompt never closes it.
- Desktop: when the PC asks before it closes the running game, Nightjar asks you instead of showing an error and starts the game once you confirm.

## de
- Wenn auf einem Rubylight-PC schon ein Spiel läuft, schließt der Start eines anderen es nur, wenn du die Abfrage bestätigst. Ein gemerkter Start oder eine abgebrochene Abfrage schließt es nie.
- Desktop: Fragt der PC, bevor er das laufende Spiel schließt, fragt Nightjar dich, statt einen Fehler zu zeigen, und startet das Spiel, sobald du bestätigst.
