## en
- Logs name what started each stream (library, shortcut, frontend, reconnect), and shared logs no longer cut a setting off from its value.
- Desktop: a wrong command line from a frontend (with `--host`) no longer opens a usage box behind it.
- German: consistent wording for decoding and network changes.

## de
- Logs nennen, was einen Stream gestartet hat (Bibliothek, Verknüpfung, Frontend, Wiederverbindung), und geteilte Logs trennen keine Einstellung mehr von ihrem Wert.
- Desktop: Eine falsche Befehlszeile von einem Frontend (mit `--host`) öffnet kein Hilfefenster mehr dahinter.
- Deutsch: einheitliche Begriffe für Dekodierung und Netzwerkwechsel.
