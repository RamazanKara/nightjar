## en
- Nightjar for Windows and Linux: Settings shows each section's main rows first, the same ones as on Android, and keeps the rest behind "More … settings" at the end of the section. A setting a PC or profile overrides stays in view.
- Desktop names match Android: **Device controls bitrate**, **Recover interrupted streams**, and under Advanced Loss-based bitrate (Rust engine), Full chroma and a Diagnostics group (Tell the PC when on Wi-Fi, Tell the PC the link speed, the link test). The performance overlay moved to Streaming, clipboard sync to Controls, Video size to Display & image.
- No setting or page carries an Experimental label any more.
- **Recover interrupted streams** is now on by default on Windows and Linux too, including in settings saved before; turning it off again is kept.
