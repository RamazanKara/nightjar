## en
- Variable refresh on a screen without Android 16's adaptive refresh rate still runs at the screen's top rate. With a Rubylight PC, it now follows the game's frame rate where the screen can switch without blanking, for example 90 Hz for a 90 fps game on a 90/120 Hz phone. A 60 fps game on a 120 Hz screen stays at 120 Hz.
- On screens with adaptive refresh rate, the stream asks for its own frame rate instead of leaving it at Android's 60 Hz default for games. If the screen still shows only half the frames, the Statistics overlay says so.
