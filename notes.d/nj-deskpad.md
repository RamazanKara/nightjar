## en
- Desktop: holding the D-pad or a stick in the PC and game lists keeps moving, slowly at first and then faster, so long lists no longer take a press per step.
- Desktop: controller hints name the buttons of the connected controller: PlayStation symbols, Switch labels or Xbox names.
- Desktop on Windows: a new "Touchpad gestures on the PC" setting (off by default) sends a precision touchpad's fingers to a PC that takes them, so multi-finger gestures work there. Other PCs get the pointer as before.
- Desktop on Windows: Nightjar now uses Windows' segment heap, the memory allocator Windows offers newer apps.
