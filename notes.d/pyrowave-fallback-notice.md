## en
- When PyroWave is chosen and the stream runs another codec, Nightjar now says so once per PC, with the codec it uses and why: this device can't run PyroWave (for example a 32-bit app, or its display couldn't be set up), the PC has no PyroWave (or none in HDR), or Full chroma is on.
- On a device that can never run PyroWave, the codec list says why next to PyroWave, for all PCs and in each PC's own settings.
