Download. Install. Stream.

  1. Open the latest release and download the APK.
  2. Verify the file using the commands below. Open the APK on your Android device.
  3. Allow installation from your browser or file manager when Android asks. Install Nightjar.
  4. On Windows, download nightjar-desktop-<version>-windows-x86_64.zip, unzip it and run nightjar.exe. On Linux, download nightjar-desktop-<version>-linux-x86_64.tar.gz, unpack it and run ./nightjar.
  5. Start your PC’s streaming host, for example Apollo, Rubylight, Sunshine or Vibepollo. Then follow the four-step setup.

Check your download.

Open a terminal in the folder containing the download. Calculate its SHA-256 hash with the command for your system.

Windows · PowerShell

Get-FileHash .\*.apk -Algorithm SHA256

Linux

sha256sum ./*.apk

macOS

shasum -a 256 ./*.apk

Open the release checksum data. Under assets, find your APK’s name and its digest. Compare the 64-character value after sha256: with your result. Every value must match. Letter case does not matter.

Install the file once the checksum matches. Download it again from the release page to resolve a mismatch.
