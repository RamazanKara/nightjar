Download the package for your device from the latest GitHub release, verify its checksum below, and pair with Rubylight, Apollo, Sunshine or Vibepollo.

Android 7.1+

Phone, Handheld & TV

Download the universal .apk (or the smaller arm64-v8a APK), open it on your phone, Android handheld, Android TV or Fire TV, and allow installation when asked.

Windows 10 & 11

x64 & ARM64 Desktop

Run nightjar-desktop-<version>-windows-x86_64-setup.exe (or …-windows-arm64-setup.exe on Snapdragon X PCs). Installs per-user without admin rights and preserves paired PCs on update; portable .zip also available.

Linux & Steam Deck

Packages, AppImage & Flatpak

Install the .deb on Debian/Ubuntu or the .rpm on Fedora. On SteamOS and other distributions, install the .flatpak, run the .AppImage, or unpack the .tar.gz.

macOS 13+

Apple Silicon & Intel

Unpack nightjar-desktop-<version>-macos-arm64.zip (or …-macos-x86_64.zip) and drag Nightjar.app to Applications. Because builds are not Apple-notarized, approve once via Open Anyway in System Settings → Privacy & Security (macOS 15+) or Control-click → Open (macOS 13–14).

Check your download.

Open a terminal in your Downloads folder and compute the SHA-256 hash of the installer, archive or APK you downloaded.

Windows · PowerShell

Get-FileHash .\nightjar* -Algorithm SHA256

Linux

sha256sum ./nightjar* ./*.apk 2>/dev/null

macOS

shasum -a 256 ./nightjar* ./*.apk 2>/dev/null

Compare the 64-character hex digest against the GitHub release page (shown next to each asset) or the release checksum JSON under assets[].digest. Case does not matter; re-download from GitHub if any digit differs.
